Device: Windows 10 IoT Enterprise LTSC 2021, Intel Core i3-1115G4E, Intel UHD Graphics, cameras `TDOC_STB_FIXED` and
`TDOC_STB_PTZ`. Built on a Windows PC (VS 2022, `x64-windows-static-md`, Release, 0 warnings) from
`feat/eme-006-mf-h264-encoder` and copied to the device; run over SSH, with the viewer and Edge launched on the device's
console session.

Windows-only, so the Linux build never compiled it.

taken with two viewers connected, the OpenH264 one with one. Rerun with one viewer for a like-for-like number.

The read-back line appears twice per camera because the encoder reads its settings again after the MFT renegotiates its
output type (Quick Sync does this after the first frame); each encoder is created once.
